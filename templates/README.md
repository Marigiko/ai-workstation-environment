# Templates
# Project templates for rapid scaffolding

## Available Templates

- `fastapi/` — FastAPI project with Docker, tests, CI
- `scraper/` — Web scraper with error handling, rate limiting
- `rag/` — RAG pipeline with embeddings, vector DB

## Usage

```bash
# Copy template to new project
cp -r templates/fastapi ~/my-new-project
cd ~/my-new-project
# Customize as needed
```
