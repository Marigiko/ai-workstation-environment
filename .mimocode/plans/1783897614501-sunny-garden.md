# Plan: AI Workstation — Unified Workflow & Installer

## Objective

Fusionar 3 proyectos desconectados (terax-ai, ai-workstation, ai-workstation-environment) en un flujo de trabajo unificado:
- **Windows**: Doble-click en acceso directo con icono → Terax se abre como app nativa (no terminal)
- **Linux**: Un comando instala todo
- **Usuario no técnico**: No necesita saber programación

**Arquitectura objetivo**:
```
Usuario doble-click en icono (Windows)
│
▼
┌─────────────────────────────┐
│ Terax (Tauri app, GUI)      │ ← No bloquea terminal
│ Puerto: app window          │
└────────┬────────────────────┘
         │ HTTP localhost:8000
         ▼
┌─────────────────────────────┐
│ AI Workstation Gateway      │ ← FastAPI (backend definitivo)
│ Routing / Memory / MCP      │
└────────┬────────────────────┘
         │ HTTP localhost:4000
         ▼
┌─────────────────────────────┐
│ LiteLLM Proxy               │ ← Docker
└────────┬────────────────────┘
         │
         ▼
    Ollama / Gemini / Claude / GPT-4...
```

## Decisiones clave (validadas por usuario)

1. **Tauri (Plan B)** para Terax en Windows — NO WSLg. Desarrollo profesional, instalador .msi posible.
2. **ai-workstation es backend definitivo** — environment NO tiene backend propio.
3. **Windows primero** — prioridad de implementación.
4. **Herramientas gratuitas** — PowerShell/VBS, no Inno Setup.
5. **Security audit** — eliminar API keys hardcodeadas antes de release.
6. **Fusion de repos** — environment depende de ai-workstation, no al revés.
7. **No pedir aprobación** — usuario quiere ejecución autónoma (requiere config de permisos en .mimocode/config.yaml).
8. **Git token** — configurar en WSL para evitar bloqueos.

## Fase 2: Configuración de permisos y Git

### 2a. Configurar permisos de ejecución automática

El usuario quiere que se ejecute código sin pedir aprobación. Esto se configura en `.mimocode/config.yaml`:

```yaml
permissions:
  # Allow all bash commands without asking
  - permission: bash
    action: allow
    pattern: "*"
  # Allow all file edits without asking
  - permission: edit
    action: allow
    pattern: "*"
  - permission: write
    action: allow
    pattern: "*"
```

**Ubicación**: `/mnt/e/Projects/ai-workstation-environment/.mimocode/config.yaml`

### 2b. Configurar Git token en WSL

Configurar el access token proporcionado por el usuario para evitar bloqueos de autenticación:

```bash
# En WSL:
git config --global credential.helper cache
# O usar store (persistente):
git config --global credential.helper store

# Configurar GitHub CLI con el token:
echo "TOKEN_AQUI" | gh auth login --with-token
```

**NOTA DE SEGURIDAD**: El token NO debe escribirse en ningún archivo del repo ni en este plan. Se configurará interactivamente durante implementación.

## Fase 6: Instalador Windows unificado

### 6a. Script principal: `scripts/windows/install.ps1`

```powershell
# install.ps1 — Doble-click installer para Windows
# 1. Verificar WSL instalado
# 2. Si no → instalar WSL (wsl --install)
# 3. Instalar Docker Desktop si no existe
# 4. En WSL: ai-workstation-environment bootstrap
# 5. Crear acceso directo Terax en Desktop
# 6. Crear acceso directo "AI Workstation Console"
```

### 6b. Acceso directo: `scripts/windows/launch-terax.vbs`

```vbs
' launch-terax.vbs — Invisible launcher (sin ventana negra)
Set WshShell = CreateObject("WScript.Shell")

' Verificar que gateway está corriendo
checkCmd = "wsl -d Ubuntu -- bash -c 'curl -sf http://localhost:8000/health'"
returnCode = WshShell.Run("cmd /c " & checkCmd, 0, True)

If returnCode <> 0 Then
    ' Arrancar gateway
    WshShell.Run "wsl -d Ubuntu -- bash -c 'cd /mnt/e/Projects/ai-workstation && docker compose -f infrastructure/compose/docker-compose.yml up -d'", 0, True
    WScript.Sleep 10000
End If

' Arrancar Terax
WshShell.Run "wsl -d Ubuntu -- bash -c 'cd /mnt/e/Projects/terax-ai && pnpm tauri dev'", 0, False
```

### 6c. Crear acceso directo .lnk: `scripts/windows/create-shortcut.ps1`

```powershell
# Crea acceso directo en Desktop con icono de Terax
$WshShell = New-Object -ComObject WScript.Shell
$Shortcut = $WshShell.CreateShortcut("$env:USERPROFILE\Desktop\Terax AI Workstation.lnk")
$Shortcut.TargetPath = "wscript.exe"
$Shortcut.Arguments = "`"C:\path\to\launch-terax.vbs`""
$Shortcut.IconLocation = "C:\path\to\terax-icon.ico"
$Shortcut.Save()
```
