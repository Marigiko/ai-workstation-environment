# Tradeoff Analysis Prompt

Analyze the tradeoffs between the following options:

## Options
- **Option A**: [Description]
- **Option B**: [Description]
- **Option C**: [Description]

## Evaluation Criteria
- Performance
- Complexity
- Maintainability
- Cost (development and operational)
- Scalability
- Developer experience

## Deliverables

1. **Comparison Matrix**: Score each option against criteria (1-5)
2. **Pros/Cons**: List advantages and disadvantages for each
3. **Recommendation**: Which option and why
4. **Migration Path**: If we choose wrong, how hard to switch?

Be objective. Consider both short-term and long-term implications.
