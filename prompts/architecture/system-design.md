# System Design Prompt

You are a senior software architect. Design a system for the following requirements:

## Requirements
- [List functional requirements]
- [List non-functional requirements]
- [List constraints]

## Deliverables

1. **Component Diagram**: Identify main components, their responsibilities, and interactions
2. **Data Flow**: Describe how data moves through the system
3. **API Design**: Define key interfaces and contracts
4. **Storage Strategy**: Choose appropriate storage for each data type
5. **Scalability Considerations**: How does the system scale?
6. **Failure Modes**: What can go wrong and how to handle it

## Format

Use Mermaid diagrams where appropriate. Be specific about technologies and patterns.
