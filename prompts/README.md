# Prompts Library
# Organized collection of reusable prompts

## Categories

- `architecture/` — System design, component diagrams, tradeoff analysis
- `coding/` — Implementation patterns, refactoring, code generation
- `review/` — Code review, security audit, performance analysis
- `planning/` — Project planning, task breakdown, estimation
- `debug/` — Troubleshooting, log analysis, root cause investigation
- `documentation/` — README generation, API docs, inline comments
- `security/` — Vulnerability assessment, threat modeling, secure coding

## Usage

Prompts are referenced by workflows or used directly with AI tools.

Example:
```
@prompts/coding/fastapi-endpoint.md
```
