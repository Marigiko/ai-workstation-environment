## Implementation Guidelines

1. **Single Responsibility**: Each function/class does one thing
2. **Descriptive Names**: Variables, functions, classes clearly express intent
3. **Small Functions**: Max 20 lines, ideally < 10
4. **No Comments**: Code should be self-documenting
5. **DRY**: Extract common patterns into helpers
6. **Fail Fast**: Validate inputs early
7. **Immutable by Default**: Prefer const/final, avoid mutation
