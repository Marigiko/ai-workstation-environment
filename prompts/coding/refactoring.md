# Refactoring Prompt

Refactor the following code to improve quality without changing behavior:

## Code to Refactor
```
[Paste code here]
```

## Current Issues
- [List known problems: complexity, duplication, poor naming, etc.]

## Refactoring Goals
- [ ] Improve readability
- [ ] Reduce complexity
- [ ] Eliminate duplication
- [ ] Better naming
- [ ] Extract reusable components
- [ ] Improve testability

## Constraints
- Maintain existing behavior
- Keep tests passing
- No breaking changes to public API

## Approach

1. **Identify Smells**: List code smells present
2. **Plan Steps**: Sequence of small, safe refactorings
3. **Execute**: Apply refactorings one at a time
4. **Verify**: Ensure behavior unchanged after each step

Use established refactoring patterns: Extract Method, Replace Conditional with Polymorphism, Introduce Parameter Object, etc.
