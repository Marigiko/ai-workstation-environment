# F5: Workflow & Automation

## Findings

### [1] Claude Code provides a comprehensive hook system with 25+ lifecycle events enabling fine-grained automation at every stage of the agentic loop
- quote: "Hooks are user-defined shell commands, HTTP endpoints, or LLM prompts that execute automatically at specific points in Claude Code's lifecycle."
- url: https://docs.anthropic.com/en/docs/claude-code/hooks
- source_type: primary
- published: unknown (accessed 2026-07-07)
- confidence: high

### [2] Claude Code hooks support five handler types — command, HTTP, MCP tool, LLM prompt, and agent — each with matcher-based filtering and conditional execution
- quote: "Each object in the inner hooks array is a hook handler: the shell command, HTTP endpoint, MCP tool, LLM prompt, or agent that runs when the matcher matches."
- url: https://docs.anthropic.com/en/docs/claude-code/hooks
- source_type: primary
- published: unknown (accessed 2026-07-07)
- confidence: high

### [3] Claude Code hooks include PreToolUse/PostToolUse events that fire on every tool call, enabling real-time validation, logging, and blocking of tool invocations
- quote: "Events fall into three cadences: once per session: SessionStart and SessionEnd; once per turn: UserPromptSubmit, Stop, and StopFailure; on every tool call inside the agentic loop: PreToolUse and PostToolUse."
- url: https://docs.anthropic.com/en/docs/claude-code/hooks
- source_type: primary
- published: unknown (accessed 2026-07-07)
- confidence: high

### [4] Claude Code supports async hooks that run in the background without blocking the agent, enabling non-blocking test execution and monitoring after file changes
- quote: "For long-running tasks like deployments, test suites, or external API calls, set 'async': true to run the hook in the background while Claude continues working."
- url: https://docs.anthropic.com/en/docs/claude-code/hooks
- source_type: primary
- published: unknown (accessed 2026-07-07)
- confidence: high

### [5] Claude Code subagents support custom hooks, MCP server scoping, worktree isolation, and cross-session memory for persistent multi-agent workflows
- quote: "Subagents support lifecycle hooks scoped to this subagent. Use the mcpServers field to give a subagent access to MCP servers that aren't available in the main conversation."
- url: https://docs.anthropic.com/en/docs/claude-code/sub-agents
- source_type: primary
- published: unknown (accessed 2026-07-07)
- confidence: high

### [6] Claude Code introduced Routines and Desktop scheduled tasks for recurring automation, running on Anthropic-managed infrastructure independent of local machines
- quote: "Routines run on Anthropic-managed infrastructure, so they keep running even when your computer is off. They can also trigger on API calls or GitHub events."
- url: https://docs.anthropic.com/en/docs/claude-code/overview
- source_type: primary
- published: unknown (accessed 2026-07-07)
- confidence: high
