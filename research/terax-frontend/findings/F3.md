# F3: Terax MCP & Model Support

## Findings

### [1] Terax does not currently support MCP protocol, but users have requested it
- quote: "Please add a feature to add, change, or toggle MCPs from the settings."
- url: https://github.com/crynta/terax-ai/issues/378
- source_type: community
- published: May 20, 2026
- confidence: high

### [2] Terax supports any OpenAI-compatible endpoint as a provider
- quote: "OpenAI-compatible - any custom base URL that speaks the OpenAI Chat Completions / Responses shape"
- url: https://terax.app/docs/ai/providers
- source_type: primary
- published: unknown
- confidence: high

### [3] Terax has native Ollama integration with default local endpoint
- quote: "Ollama - default base http://127.0.0.1:11434"
- url: https://terax.app/docs/ai/providers
- source_type: primary
- published: unknown
- confidence: high

### [4] Terax supports 10+ cloud providers via Vercel AI SDK v6
- quote: "Built on the Vercel AI SDK v6 (@ai-sdk/*): OpenAI, Anthropic, Google (Gemini), Groq, xAI (Grok), Cerebras, OpenRouter, DeepSeek, Mistral, plus any OpenAI-compatible endpoint"
- url: https://terax.app/docs/ai/providers
- source_type: primary
- published: unknown
- confidence: high

### [5] Terax currently limits users to a single OpenAI-compatible provider configuration
- quote: "Currently, Terax AI only allows adding a single OpenAI-compatible provider at a time."
- url: https://github.com/crynta/terax-ai/issues/496
- source_type: community
- published: May 25, 2026
- confidence: high

### [6] Terax supports LM Studio and MLX as local/offline model providers
- quote: "LM Studio - default base http://127.0.0.1:1234/v1, MLX - default base http://127.0.0.1:8080/v1, optimized for Apple Silicon"
- url: https://terax.app/docs/ai/providers
- source_type: primary
- published: unknown
- confidence: high

### [7] Provider routing is handled by Vercel AI SDK, not custom model routing logic
- quote: "AI provider routing is handled by the Vercel AI SDK."
- url: https://terax.app/about
- source_type: primary
- published: unknown
- confidence: high

### [8] Terax ROADMAP does not mention MCP support in planned features
- quote: (No mention of MCP in ROADMAP.md planned or longer horizon sections)
- url: https://github.com/crynta/terax-ai/blob/main/ROADMAP.md
- source_type: primary
- published: unknown
- confidence: high
